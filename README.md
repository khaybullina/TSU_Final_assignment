# 🛒 Retail Transaction Data Analysis

## 📌 Overview
This repository contains a data analysis project focused on retail transactions.  
The goal is to explore customer behavior and product performance using Python and Pandas.

---

## 🔎 What Was Done
- Loaded and cleaned data (`customers.csv`, `product.csv`, `transactions.csv`)  
- Merged tables to create a combined dataset  
- Performed exploratory data analysis (EDA)  
- Identified top products by revenue and popularity  
- Analyzed sales patterns and customer age groups  
- Tested a hypothesis about club membership and purchase count  
- Clustered customers using key behavioral features  
- Built a basic collaborative-filtering recommendation system

---

## 📈 Key Insights
- Top-selling products and most popular items identified  
- Most customers bought a small number of products  
- Club membership has a measurable effect on purchase behavior  
- Clustering revealed distinct customer segments
